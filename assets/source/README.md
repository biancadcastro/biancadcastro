Esta pasta preserva imagens e fontes de propostas anteriores do perfil; elas não são usadas pelo README atual.

O README original usa os SVGs diretamente em assets/. Os modelos dos dois painéis de estatísticas estão em assets/templates/. O workflow atualiza somente assets/metrics-custom.svg e assets/languages-custom.svg com dados reais do GitHub, preservando o estilo original.

A distribuição por repositório considera a linguagem principal de cada projeto. A distribuição por código usa os bytes de cada linguagem. As duas consultas abrangem até 100 repositórios públicos próprios, sem forks; commits, pull requests, issues e contribuições referem-se ao último ano.

Fontes preservadas nesta pasta: Pixelify Sans e Nunito, sob a SIL Open Font License, incluída nos arquivos correspondentes.
